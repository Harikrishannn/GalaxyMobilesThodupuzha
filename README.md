# Galaxy Mobiles — Premium Next.js Website

Responsive multi-page website recreated from the supplied reference UI.

## Stack
- Next.js App Router
- TypeScript
- Tailwind CSS v4
- lucide-react
- Local TypeScript data (no backend/database)

## Routes
/, /mobiles, /services, /gallery, /reviews, /enquiry, /contact

## Run
npm install
npm run dev

## Vercel
Push to GitHub and import into Vercel. No environment variables are required for the demo build.

## Edit client data
`data/site.ts` contains store contact, WhatsApp number, products, services, reviews, brands and gallery data.
